## 受控失败场景

1. 启动时设置 `SEATA_DEMO_FAIL_AFTER_REMOTE=true`。
2. 执行一次初筛结果投递。
3. 预期远程复核分支写入后出现 `SEATA_DEMO_FAIL_AFTER_REMOTE`。
4. 观察全局事务状态为回滚，复核记录不存在，答卷保持失败或原处理状态。
5. 恢复变量为 `false` 并重启，确认成功路径可正常提交。

该开关默认关闭，只用于演示和集成测试。
