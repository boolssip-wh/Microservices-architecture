# 五四论述题演示复现说明

## 1. 批次信息

| 字段 | 输入值 |
|---|---|
| 考试名称 | 五四青年节 · 新时代好青年论述题 |
| 题号 | Q1 |
| 题目标题 | 如何争做新时代好青年，早日入党 |
| 满分 | 20 |
| 基础分 | 10（允许修改） |

完整题干已经内置在“阅卷空间”，点击“＋ 新建案例”即可看到。题号只允许 1—20 位字母、数字、下划线或短横线，中文题目填写在短标题或完整题干中。

## 2. 评分规则

```text
有理想：有理想|理想信念|树立理想|听党话|跟党走|坚定信念
敢担当：敢担当|敢于担当|勇于担当|责任担当|挺膺担当
能吃苦：能吃苦|吃苦耐劳|艰苦奋斗|不怕困难|迎难而上
肯奋斗：肯奋斗|不懈奋斗|拼搏奋斗|接续奋斗|努力奋斗
作答篇幅：LENGTH_COVERAGE
```

| 要点 | 权重 | 分值 |
|---|---:|---:|
| 有理想 | 22.50 | 2.25 |
| 敢担当 | 22.50 | 2.25 |
| 能吃苦 | 22.50 | 2.25 |
| 肯奋斗 | 22.50 | 2.25 |
| 作答篇幅 | 10.00 | 1.00 |

权重合计为 `100.00`。有效作答基础分为 10 分，因此总分最高为 20 分。

## 4. 真实手写答卷

需要先配置 `VISION_API_BASE_URL`、`VISION_MODEL` 和 `VISION_API_KEY`。随后上传
JPG/JPEG、PNG 手写答卷，视觉模型会转录正文并估计作答区域覆盖率。没有配置 API
时系统会明确提示失败，不会返回伪造的识别文本。
