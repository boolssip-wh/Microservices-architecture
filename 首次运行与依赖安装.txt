同标阅卷｜源码交付包首次运行说明
版本：2026-11-12

一、这个压缩包包含什么

包含前后端源码、测试、数据库迁移 SQL、配置模板、启动/验收脚本、示例答卷、依赖版本清单，以及 docs/交付文档 中的两份新版 Word 文档。
不包含任何项目 JAR、第三方工具安装包、Maven/npm 依赖缓存、node_modules、target、dist、日志、运行数据库或用户上传文件。第一次构建需要联网，Maven 和 npm 会按版本清单下载依赖。
建议将 smartgrade-platform 文件夹解压到一个固定目录，例如 C:\SmartGradeWork\smartgrade-platform。后续命令中的“项目根目录”就是包含 start.cmd 和 pom.xml 的目录。

二、需要自行下载的组件

1. JDK 17（Windows x64）
   官方下载：https://learn.microsoft.com/en-us/java/openjdk/download
   将 JDK 解压为 C:\SmartGradeTools\jdk17，确保 bin\java.exe 存在。

2. Apache Maven 3.9.x（原开发环境为 3.9.9）
   官方下载：https://maven.apache.org/download.cgi
   将 Maven 解压为 C:\SmartGradeTools\maven，确保 bin\mvn.cmd 存在。

3. Node.js 22.x，包含 npm
   官方下载：https://nodejs.org/en/download
   安装时将 Node.js 加入 PATH。重新打开 PowerShell，确认 node --version、npm.cmd --version 能执行。

4. Nacos Server 3.3.0
   官方版本：https://github.com/alibaba/nacos/releases/tag/3.3.0
   下载发行包，解压到 C:\SmartGradeTools\nacos，确保其下直接有 bin 和 conf 目录。

5. Sentinel Dashboard 1.8.8
   官方版本：https://github.com/alibaba/Sentinel/releases/tag/1.8.8
   下载 sentinel-dashboard-1.8.8.jar，自行放到工具目录，例如：
   C:\SmartGradeTools\sentinel\sentinel-dashboard.jar
   该第三方 JAR 不包含在源码包内。

上述工具路径可以自行改变。启动脚本要求 SMARTGRADE_TOOLS 指向的目录下包含 jdk17 和 maven；Sentinel 可用 SENTINEL_DASHBOARD_JAR 指定任意绝对路径。Node/npm 从 PATH 查找。
默认本地演示采用 H2 内存数据库，不需要先安装 MySQL、Redis、Kafka、MinIO 或 Docker。需要基础设施部署时再阅读 deploy/INFRA.md，并自行安装相应组件。

三、首次启动 Nacos（只需在新电脑配置一次）

打开 C:\SmartGradeTools\nacos\conf\application.properties，确认：
  nacos.console.port=8088
  nacos.server.main.port=8848
Nacos 3.3.0 默认控制台端口为 8080，需要改成 8088，避免与本项目的网关冲突。

按 Nacos 官方要求设置鉴权参数：
  nacos.core.auth.server.identity.key
  nacos.core.auth.server.identity.value
  nacos.plugin.auth.nacos.token.secret.key
身份 key/value 使用自己设定的非空值；签名密钥使用 Base64 编码且解码后不少于 32 字节的随机值。可以在 PowerShell 生成签名密钥：
  $nacosBytes = New-Object byte[] 32
  $nacosRng = [Security.Cryptography.RandomNumberGenerator]::Create()
  $nacosRng.GetBytes($nacosBytes)
  [Convert]::ToBase64String($nacosBytes)
  $nacosRng.Dispose()
将输出值填入签名密钥配置，不要提交给源码仓库。服务身份参数、签名密钥和管理员登录密码是三类不同配置。
官方配置参考：https://raw.githubusercontent.com/alibaba/nacos/3.3.0/distribution/conf/application.properties
官方鉴权说明：https://nacos.io/docs/latest/manual/admin/auth/

在 PowerShell 执行：
  $env:JAVA_HOME = 'C:\SmartGradeTools\jdk17'
  $nacosTmp = Join-Path $env:LOCALAPPDATA 'Temp\java-unixdomain'
  New-Item -ItemType Directory -Force $nacosTmp
  $env:JAVA_TOOL_OPTIONS = "-Djdk.net.unixdomain.tmpdir=$nacosTmp"
  cd 'C:\SmartGradeTools\nacos\bin'
  .\startup.cmd -m standalone

打开 http://127.0.0.1:8088，首次访问按页面初始化 nacos 管理员密码。
新安装没有管理员默认密码。原开发电脑使用的 1111 不是安装后的通用密码，请记住自己设置的密码。

四、首次构建并启动项目

确认 Nacos 已运行。在准备启动项目的同一个 PowerShell 中设置环境变量：
  $env:SMARTGRADE_TOOLS = 'C:\SmartGradeTools'
  $env:SENTINEL_DASHBOARD_JAR = 'C:\SmartGradeTools\sentinel\sentinel-dashboard.jar'
  $env:NACOS_ADDR = '127.0.0.1:8848'
  $env:NACOS_USERNAME = 'nacos'
  $env:NACOS_PASSWORD = '替换为刚才初始化的管理员密码'
  cd 'C:\SmartGradeWork\smartgrade-platform'
  .\start.cmd

请把上述示例路径、密码换成自己的实际值。临时环境变量只对当前终端及其启动的进程生效；设置后应在同一个窗口执行 start.cmd，不要改为从资源管理器双击。以后若将这些配置设置为 Windows 用户环境变量，需重新打开终端/资源管理器才能读取。
.env.example 是变量清单，脚本不会自动读取 .env 文件。

启动脚本会先从源码构建各服务（自动下载 Maven 依赖），首次安装前端 npm 依赖，再启动 Sentinel、网关、七个业务服务及前端。首次下载较多，时间取决于网络，请等待，不要反复双击启动。
如果 Maven 镜像不可达，可由维护者调整 scripts/maven-settings.xml；npm 下载失败时检查网络/代理后重新运行。

五、第一次操作与可选图片识别

先使用 samples 中的 2026101.txt、2026102.txt、2026103.txt 演示，不需要外部图片识别服务：
新建案例（题号 Q1、满分 20、基础分 10）→创建并解析评分要点→保存并冻结→导入答卷→复核定分中查看原试卷、核对证据、确认最终分→统计报告中导出。
完整图文步骤见 docs/交付文档/同标阅卷初代产品使用说明书.docx；其中原开发电脑的工具路径和 Nacos 密码示例，以本文件中的新电脑配置方法替换。

图片和扫描 PDF 需要接收者自行开通视觉识别接口，再在启动终端配置 VISION_API_BASE_URL、VISION_MODEL、VISION_API_KEY；本包不提供 API Key。不要将真实密钥写入源码或上传。系统支持 TXT、JPG/JPEG、PNG、PDF、ZIP，不支持 WEBP 导入。
默认 H2 为内存演示模式，后端重启后批次等业务数据会重置；需要保留的成绩请先下载，长期保存需配置持久化部署。

六、停止与自行验证

普通停止：在项目根目录执行 .\stop.cmd（保留 Nacos）。
连本例 Nacos 一起停止：
  .\scripts\stop-all.ps1 -IncludeNacos -NacosHome 'C:\SmartGradeTools\nacos'

后端验证：.\scripts\mvn17.cmd clean verify
前端验证：进入 smartgrade-web，执行 npm.cmd ci、npm.cmd run build
上传幂等测试：在 smartgrade-web 中执行 node --test test/importAttempts.test.js
隔离流程验证：在项目根目录执行 .\scripts\verify-document-contract.ps1

软件包里的“包内容与校验.json”列明交付文件、SHA-256 和排除规则，可用于确认源码包内容。
